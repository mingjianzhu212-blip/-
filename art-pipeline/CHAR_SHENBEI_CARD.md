## 0. 为什么是沈碑

| 维度 | 沈碑（守碑老吏） | 是否适合验证生产线 |
|---|---|---|
| 设定完整度 | 已有冻结人设：守碑三千年、拄帚立于观前、等「碑照不出」的第二个人 | 高：无需现编，提示词有据可依 |
| 场景固定 | 观前·碑林、黑色测灵碑、月华/晨雾 | 高：角色与场景可同批验证 |
| 道具锚点 | 一柄旧竹帚（身份 + 情感双关：替玩家扫路） | 高：一致性有硬锚点 |
| 情感线 | 守 / 等 / 三千年只黑过两次 | 高：表情与氛围有明确方向 |
| 是否玩家角色 | 否，外观可固定 | 高：不必替玩家决定长相 |
| 现有素材 | `ui/avatar/npc_stele_full.jpg`（540×1170，**未被任何 js/html/css 引用**） | 中：可作 v0 对照，**不覆盖** |

| 规格 | 1080×1920 透明 PNG | 540×1170 **JPG 不透明** | ❌ 不能直接用 |

**判定：`npc_stele_full.jpg` 只能当"风格参考图"，不能当"素材"，更不能当最终形象。**
它的价值是证明"水墨写意 + 老年修士"这条路走得通；它的错误是丢了扫帚、加了金饰。

**处理（已执行）**：原文件**原样保留，未改名、未移动、未删除、未覆盖**，仅在清单里登记为 `v0_candidate`。

**同时它给出两条提示词修正**（已应用到 §2）：
1. 负面词补 **`金色发冠, 华贵金纹, 玉坠流苏`** —— 防止模型自作主张加金饰。
2. 正向词把扫帚写得**更具体**：`一柄用旧的竹扫帚，竹柄被手磨得发亮，帚毛散开、沾着灰` —— 只说"竹帚"模型会画成杖。

### 0.5.4 与崔九的区分（同批验证必看）

崔九（`js/npc_tower.js:11`，守塔老卒）与沈碑**都是老年男性**，若不做区分会"撞脸"：

| 维度 | 沈碑 | 崔九 |
|---|---|---|
| 场地 | 观前·碑林，月华 | 塔门·塔内，灯火 |
| 道具 | 竹扫帚 | 铜钥 / 灯笼（待定，需另开卡） |
| 服色 | 玄青（冷） | 赭褐/铜色（暖） |
| 气质 | 执拗的温和、看得远 | 守塔的钝、话少 |

> 沈碑全部用**冷调**（玄青+月白+月华），崔九留给**暖调**（赭褐+灯黄）。这条不同时定下来，N 类会出一对双胞胎。

## 1. 角色视觉设定卡

### 1.1 身份与气质（写进提示词的"魂"）
- 身份：守碑老吏，守一块测灵碑三千年。
- 气质关键词：**苍老而不朽、沉默、执拗的温和、看得很远**。
- 情绪基线：不悲苦、不凶戾；是"把一件事守了三千年"的平静。
- 台词锚（供氛围参考，不入提示词）："守碑的。碑在，人在。""观前的路，老夫替你扫着。"

### 1.2 外形锚点（七项锁 IP，任何变体都不得改）

> ⚠️ **性质声明**：下表七项中**只有第 7 项「旧竹帚」有代码依据**，其余六项为本卡设计补充（核对见 §0.5.2）。出图后即冻结为"设计稿设定"，对外不称"官方设定"。

1. **白发**：银白，简单木簪束起（不戴冠、不插金玉）。
2. **三缕白须**：清癯，须长过胸，不蓬乱。
3. **长眉入鬓**：白眉，眉峰清正。
4. **清癯面容**：颧骨微显、风霜皱纹，眼神沉静悠远；**国风骨相，非欧美立体、非网红脸**。
5. **玄青旧吏袍**：洗得发白，袖口下摆磨旧，素色布带束腰。
6. **朱砂腰牌**：腰间一枚暗朱砂色小腰牌（守碑吏信物），唯一亮色点缀。
7. **旧竹帚**：一柄磨得发亮的竹帚，拄地或斜倚，是核心道具。**（唯一有代码依据的一项：`js/npc.js`「拄着扫帚」「把扫帚靠在碑上」）**

> 体态：约 7 头身、清瘦；**脊背微驼但站得稳**（老而不弱）。这一条是对 `ART_PIPELINE §3.4`「7–7.5 头身·年轻修仙者脸型」的**老年 NPC 适配**：保留"国风骨相·清正不网红"，允许皱纹/白发/微驼。

### 1.3 服饰
- 主袍：玄青/黛色（`#0E1B2A` 系，做旧、低饱和），交领右衽，宽袖。
- 内衬：月白（`#DCE6F0`）露一截领口，压住整体冷调。
- 纹样：领口/袖口**极淡碑纹暗绣**（不抢眼，远看是素袍）。
- 腰：素麻布带；挂朱砂腰牌（`#B23A30`），可带一枚极小的金边（`#C8A24B`）——全图金色面积 <3%。
- 鞋：黑布履，沾薄灰（呼应"扫地"）。

### 1.4 道具
- **旧竹帚**：竹柄磨亮、帚毛微散；拄地或斜倚身侧。是他"守"的动作，也是"替玩家扫路"的情感符号。
- 可选：一盏旧纸灯（夜景用，暖光极小面积，避免破坏冷调）。

### 1.5 配色（严格对齐 `ART_PIPELINE §3.1`）
| 用途 | 色值 | 说明 |
|---|---|---|
| 主·袍/背景深部 | 玄青 `#0E1B2A` | 做旧、低饱和 |
| 主·须发/内衬/月光 | 月白 `#DCE6F0` | 冷调高光 |
| 底·留白/宣纸 | 宣纸米白 `#F2EBDD` | ≥40% 画面留白 |
| 点缀·腰牌/印 | 朱砂 `#B23A30` | 唯一暖色，面积 ≤5% |
| 点缀·簪/金边 | 金 `#C8A24B` | 极少量，≤3% |
| 笔触/描边 | 墨黑 `#1A1A1A` | 飞白晕染 |

> 单图主色 ≤3；灵光/辉光面积 ≤12%；整体冷调，靠朱砂一点"活气"。

### 1.6 姿态与表情
- **主姿态（P1 全身）**：侧身微转，一手拄竹帚、一手拢袖；目视远方（望向碑/天门方向），背微驼、重心稳。
- **表情三态**：
  - ① 沉静守碑（默认，眼神平远）
  - ② 追忆往事（目光微垂，眉间一点怅然，不落泪）
  - ③ 温和颔首（对承诺/道别，嘴角极浅的弧度）

### 1.7 场景与光影
- **主场景**：道观观前·碑林。一块黑色测灵碑矗立，碑面一道极细裂纹 + 淡朱砂禁制纹；碑前薄灰与扫帚痕；远山淡墨、云海留白。
- **光影**：
  - **月华**（主，夜守碑）：冷青 + 月白柔光，碑面反一点冷光。
  - **晨雾**（备，清晨扫阶）：冷青薄雾 + 体积光，竹帚扬起微尘。
- 构图：三分法，主体偏下/偏侧，留白 ≥40%，竖屏优先 9:16。

### 1.8 一致性要求（参考图库，落地 §3.4）
每位常驻角色建 5 张参考图，锁定 IP：
1. 正面全身立绘（P1）
2. 半身胸像（P2）
3. 方形头像（P3）
4. 表情三连（P4）
5. 服装/腰牌/竹帚细节特写（P4b，可选）

后续生图一律以「参考图 + 画风保持 +（按需）姿势保持」为输入；**七项外形锚点**任何一项不得漂移。

### 1.9 禁止项（打回线）
- 网红脸 / 锥子脸 / 欧美立体骨相 / 韩系花美男。
- 华服金冠、满身金玉（他是清贫守碑吏，不是仙尊）。
- 塑料感高光、3D 默认渲染、卡通粗描边、重度磨皮。
- 血腥、恐怖、过度悲苦。
- 背景塞满、无留白、光污染。

### 3.1 尺寸 / 格式 / 透明背景
| 用途 | 建议尺寸 | 格式 | 背景 | 备注 |
|---|---|---|---|---|
| 全身立绘（叠加场景） | **1080×1920**（9:16） | PNG-24 | **透明 alpha** | 便于叠到 scene-bg；若作独立卡面则用宣纸米白不透明 |

| 方形头像/图标 | **512×512**（显示 360×360） | PNG-24 | 透明 alpha | 与 `av_m_bai` 同规格的 2× 源 |
| 场景 | **1080×1920** 竖 / **1920×1080** 横 | JPG 或 PNG | **不透明** | 同 `scene-bg.jpg` 用途 |
| 表情三连 | 同半身 1080×1440 | PNG-24 | 透明 alpha | 逐张 |

- 透明背景只对"角色/道具/图标"类；**场景一律不透明**。
- 出图后统一转 sRGB，避免偏色。

### 3.2 目录 / 命名 / 版本
- 目录（NPC 统一）：`ui/npc/`（新建；玩家头像仍留 `ui/avatar/`）。
