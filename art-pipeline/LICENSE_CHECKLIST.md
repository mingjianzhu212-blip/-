## 0. 为什么这份清单现在就要建

一个月的会员生产结束后，最贵的错误不是"图不好看"，而是**图很好看但不能商用**。等游戏要上线/上架/接广告时才发现授权有问题，等于全部素材重做。

所以授权核验不是"上线前再说"，而是**开会员之前就要把问题列清楚**，开通当天顺手核实、留证。

## 2. 待核实问题清单（开会员当天逐条查，查一条记一条）

> 每条都要填：**结论 / 依据原文摘录 / 依据所在页面 URL / 抓取日期 / 截图文件名**。口头答复不算。

### Q1 · 会员期内生成的图，会员到期后能否继续商用？

- **为什么重要**：这决定"停会员后游戏还能不能继续用这些图"。若条款要求"商用权随会员终止"，则一个月会员做的图全部有风险。
- **怎么查**：
  1. 会员购买页的「权益说明」全文；
  2. 平台《用户协议》中"生成内容"与"知识产权"章节；
  3. 平台《会员服务协议》中"服务终止/到期"章节。
- **要看的关键措辞**：是"**授予使用权**"（永久，不随会员终止），还是"**仅在会员期内可使用**"。
- **当前结论**：⬜ 待核实

### Q2 · 商用授权是否受「生成时间 / 会员等级 / 使用模型」限制？

- **为什么重要**：同一平台可能规定"基础会员仅个人使用、专业会员可商用"；或"某模型生成内容不可商用"。
- **怎么查**：会员档位对比表 + 模型说明页；特别看是否有"仅限 XX 档以上可商用"字样。
- **当前结论**：⬜ 待核实

### Q3 · 游戏公开发布 / 商业运营 / 游戏内展示，是否在授权范围内？

- **为什么重要**：很多平台条款允许"个人使用/社交媒体发布"，但**明确排除"嵌入商业产品/游戏"**。这是最容易被忽略的一条。
- **怎么查**：条款中"使用范围"条款，看是否列举"游戏、应用、软件产品"；是否有"不得用于商业产品或服务"的排除条款。
- **当前结论**：⬜ 待核实

### Q4 · 是否需要保留生成记录、订单、授权凭证？保留多久？

- **为什么重要**：将来被质疑时，**举证责任在自己**。没有凭证 = 无法证明合法来源。
- **怎么查**：条款中的"记录保存""争议处理"条款；平台是否提供"生成记录导出"。
- **当前结论**：⬜ 待核实
- **无论结论如何，本项目都按最严标准执行**：见 §4。

### Q5 · 免费档（不购会员）生成的图，是否可用于商业项目？

- **为什么重要**：现有 38 张妖兽图若来自免费档，可能直接不能用。
- **怎么查**：免费档的权益说明与水印政策。
- **当前结论**：⬜ 待核实（**这条直接决定 §1 里 38 张图的命运**）

### Q6 · 生成内容是否带平台水印 / 隐形水印？能否去除？

- **为什么重要**：带水印的图不能进正式包；去水印可能被条款禁止。
- **怎么查**：会员权益说明；实测出图（D1 必做）。
- **当前结论**：⬜ 待核实

### Q7 · 走 API（火山引擎）而非网页端，商用授权是否不同？

- **为什么重要**：企业 API 通常有独立商用条款，与 C 端会员不同；价格、实名要求也不同。
- **怎么查**：火山引擎方舟/即梦相关服务的「服务协议」与「计费说明」。
- **当前结论**：⬜ 待核实（本轮**不调用**，仅登记）

### Q8 · 生成内容的知识产权归属（是否归平台/是否需授权回授）？

- **为什么重要**：部分条款写"生成内容权利归平台，用户获非独占许可"，影响后续维权与二次开发。
- **怎么查**：用户协议"知识产权"章节。
- **当前结论**：⬜ 待核实

### Q9 · 若使用「参考图保持形象」功能，参考图本身的版权是否有额外要求？

- **为什么重要**：本项目要用 P1 作参考图生成 P2–P6。若参考图是 AI 生成的，条款可能对"以 AI 图作输入"另有规定。
- **怎么查**：功能说明 + 条款中"上传内容"相关章节。
- **当前结论**：⬜ 待核实

### Q10 · 现有 38 张妖兽图 / 3 张玩家立绘的来源与授权（追溯）

- **为什么重要**：已在游戏中上线，是既成事实；若不合法，需要重做。
- **怎么查**：查历史生成记录（若有）；无记录则按"来源不明"处理，**标记为待重做候选**。
- **当前结论**：🔴 **来源不明（无元数据、CREDITS 未登记）**——需制作人确认当时用的平台与档位。

## 4. 本项目自设的最严留证标准（不依赖条款结论，先做再说）

即使 Q4（是否需留证）核实为"不需要"，本项目仍按下列标准执行——**成本极低，收益是将来能自证**：

| 留什么 | 怎么留 | 存哪 |
|---|---|---|
| 会员订单 | 截图（含订单号、档位、起止日期、金额） | `art-pipeline/license/orders/` |
| 平台条款原文 | 关键页面**打印为 PDF 或长截图**，文件名带抓取日期 | `art-pipeline/license/terms/YYYY-MM-DD_*.pdf` |
| 每张定稿的来源 | 生成日期 / 平台 / 模型 / 档位 / 是否会员期内 / 有无水印 | `art-pipeline/production/<批次>/batch.md` + `ui/CREDITS.txt` |
| 原始出图 | 保留 `raw/`（含淘汰图） | `art-pipeline/production/<批次>/raw/` |
| 生成记录导出 | 平台若支持导出，每月导出一次 | `art-pipeline/license/records/` |

> 一句话：**将来若要证明"这些图是合法生成的"，唯一靠得住的是当时留的这些东西。**
