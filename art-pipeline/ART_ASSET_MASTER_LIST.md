## 2. 分级与验收标准

### 2.1 三级定义（严格按"玩家多久看到一次"分）

| 级别 | 定义 | 处理策略 |
|---|---|---|
| **A** | 上线必需。玩家**每次进游戏都会看到**（战斗双方、主场景、两位 NPC、道途选择） | 会员期内**必须完成**，未完成不上线 |
| **B** | 可后补。**特定玩法才看到**（Boss 立绘、论剑台、剧情插画、活动 banner） | 会员期内尽量做，做不完不影响上线 |
| **C** | 暂不值得生成。**CSS 已能做、生成反而更差**（面板边框、按钮装饰、材质纹理、空态插画） | **明确不做**，避免浪费会员额度 |

### 2.2 验收标准编号（清单里只填编号，正文在此定义）

| 编号 | 适用 | 验收内容 |
|---|---|---|
| **QA-A1** | 角色立绘 | 透明 alpha 边缘干净无白边；七项/五项锚点全中且与参考图不漂移；留白 ≥40%（纯场景图例外）；主色 ≤3；缩到 200px 高仍能认出是谁 |
| **QA-A2** | 头像/徽记 | 1:1 方图，主体居中，四周留白；缩到 **64px 仍可辨**（这是硬指标，因为侧栏/大厅就用这个尺寸） |
| **QA-B1** | 场景 | 无人物（或仅远景剪影）；留白 ≥35%；竖版 9:16 与横版 16:9 各出一版或一版可裁切；不得出现文字/招牌/水印 |
| **QA-B2** | Boss/怪物立绘 | 剪影清晰可立刻辨认物种；体格有压迫感但不血腥恐怖；与同族 384 图标气质一致（不能像另一只兽） |
| **QA-C1** | 道具图标 | 384×384 透明，与现有 `ui/icons/` 同笔触同透视（微俯视 3/4）；在 40px 列表行内可辨 |
| **QA-C2** | 技能图标 | 1:1，符号化（不画人），单色水墨 + 一点朱砂；在 48px 按钮内可辨；同系（剑/体/丹/阵）风格统一 |
| **QA-U** | 全部 | 无水印；授权状态已登记；单张 ≤500KB（场景 ≤800KB）；sRGB；命名符合 §5.2 |

## 6. 结论

1. **游戏不是"缺美术"，是"缺角色与场景"**。图标体系（112 张）已经完整且合格，58% 的资产需求已经满足。
2. **真正要做的是 21 张 A 级图**：玩家立绘 2 + 头像 1 + 道途徽记 4 + 两位 NPC 11 + 三大场景 3。
3. **C 级 12 张明确不做**，因为 CSS 已实现且效果更好（尤其 UI 边框与技能特效）。
4. 一个月的会员期做 **21 张 A + 约 15 张 B** 是宽松的；瓶颈不在生图，在**筛图与返工**。
