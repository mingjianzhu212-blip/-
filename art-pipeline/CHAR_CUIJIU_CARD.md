### 0.5.3 与沈碑的冷暖分野（本卡核心，防撞脸）

沈碑与崔九**都是老年男性、都是"守×老×"**，若不做区分会出一对双胞胎。分野纪律（源自沈碑卡 §0.5.4，本卡落实）：

| 维度 | 沈碑（冷） | 崔九（暖） |
|---|---|---|
| 场地 | 观前·碑林，月华 | 塔门·塔内，灯火 |
| 主色 | 玄青/月白（冷） | 赭褐/铜色（暖） |
| 点缀 | 朱砂腰牌（唯一暖点） | 灯黄微光（暖点），玄青塔影收口 |
| 道具 | 旧竹帚 | 铜钥 + 旧纸灯笼 |
| 气质 | 执拗的温和、看得远 | 守塔的钝、话少、不慌 |
| 光 | 月华冷照 | 灯火暖照 |

> 一句话：**沈碑是"冷夜里的静守"，崔九是"暗塔里的暖灯"。** 两条不同时定下来，N 类必出双胞胎。

## 1. 角色视觉设定卡

### 1.1 身份与气质（写进提示词的"魂"）
- 身份：守塔老卒，守一座镇妖塔几十年。
- 气质关键词：**钝拙、话少、不慌、护短式的沉稳**（和沈碑"执拗的温和"区分开——崔九不锋利，是"塔在人在"的钝）。
- 情绪基线：不凶戾、不悲苦；是"把一桩事守成了习惯"的平静，带一点旧年沉淀的温。
- 台词锚（供氛围参考，不入提示词）：「老朽崔九，守着这塔。客从何来？」「守塔第一桩：莫回头。」

### 1.2 外形锚点（五项锁 IP，任何变体都不得改）

> 性质声明：下表五项中**全部为设计补充**（崔九代码无外形描述，仅"老朽/胡子白"暗示年迈）。出图后即冻结为"设计稿设定"，对外不称"官方设定"；但**暖调分野**是不可妥协的生产纪律（见 §0.5.3）。

1. **灰白须发**：灰白，简单束起或披散，不戴冠。
2. **圆脸平和**：面庞偏圆润，皱纹但不刻薄，眼神钝拙温吞。
3. **赭褐铜色旧役袍**：洗旧、低饱和，交领右衽，袖口磨亮；**素净无金绣**（与沈碑同样"清贫"，但色相走暖）。
4. **铜钥 + 旧纸灯笼**：腰间一枚旧铜钥（塔门信物），一手提一盏旧纸灯笼（暖黄微光，呼应"火把不可灭"）——是核心道具与暖点。
5. **灯黄微光**：全图唯一暖光来源，面积小，靠玄青塔影压住，不泛滥。

> 体态：约 7 头身、清瘦；**脊背微驼但站得稳**（老而不弱），同沈碑老年 NPC 适配（国风骨相·清正不网红），允许皱纹/灰白发/微驼。

### 1.3 服饰
- 主袍：赭褐/铜色（`#6B4A2B`/`#B87333` 系，做旧、低饱和），交领右衽，宽袖。
- 内衬：月白（`#DCE6F0`）露一截领口，压住暖调不浮。
- 腰：素布带 + 旧铜钥（`#B87333` 暗铜）。
- 鞋：黑布履，沾薄尘（呼应"守塔"）。

### 1.4 道具
- **旧纸灯笼**：竹骨纸罩，透出暖黄微光（面积 ≤8%），是他"守塔照明"的情感与暖点符号。
- **旧铜钥**：塔门信物，挂在腰间，金属冷调但面积极小（≤3%），与灯黄形成"冷暖各一"的收口。

### 1.5 配色（严格对齐 `ART_PIPELINE §3.1`，并落实冷暖分野）
| 用途 | 色值 | 说明 |
|---|---|---|
| 主·袍 | 赭褐 `#6B4A2B` / 铜色 `#B87333` | 做旧、低饱和（暖） |
| 主·塔影/背景深部 | 玄青 `#0E1B2A` | 压住暖调，冷收口 |
| 底·留白/宣纸 | 宣纸米白 `#F2EBDD` | ≥35% 画面留白（场景例外） |
| 点缀·灯黄 | 灯黄 `#E8C56A` | 唯一暖光，面积 ≤8% |
| 点缀·铜钥 | 暗铜 `#B87333` | ≤3%，冷金属收口 |
| 笔触/描边 | 墨黑 `#1A1A1A` | 飞白晕染 |

> 单图主色 ≤3；灵光/辉光面积 ≤12%；整体**暖调为主、玄青收口**，靠灯黄一点"活气"，与沈碑"冷调为主、朱砂一点"形成镜像。

### 1.6 姿态与表情
- **主姿态（P1 全身）**：一手提灯、一手拄塔门石框（或斜倚塔门），微微侧身，目视来者；背微驼、重心稳；身后塔门幽深、灯火暖照。
- **表情三态**：
  - ① 钝拙守门（默认，眼神平、不抬头）
  - ② 旧年怅然（想起同袍，眉间一点沉，不落泪）
  - ③ 浅淡颔首（对熟客/道别，极浅弧度）

### 1.7 场景与光影
- **主场景**：镇妖塔·塔门夜景。古塔巍然，塔门幽深，门前石阶染尘，两侧石灯暖黄微光；塔影以玄青压住，远山淡墨，云气留白。
- **光影**：**灯火暖照**（主，塔内/塔门）+ 极淡冷青塔影反差。电影级玄幻场景，纵深深远，主体偏下，留白 ≥35%。
- 构图：三分法，主体偏下/偏侧，留白 ≥35%，竖屏优先 9:16。

### 1.8 一致性要求（参考图库，落地 §3.4）
每位常驻角色建 5 张参考图，锁定 IP：
1. 正面全身立绘（P1）
2. 半身胸像（P2）
3. 方形头像（P3）
4. 表情三连（P4）
5. 服装/铜钥/灯笼细节特写（P4b，可选）

后续生图一律以「参考图 + 画风保持 +（按需）姿势保持」为输入；**五项外形锚点**任何一项不得漂移；**暖调分野**是沈碑/崔九共用的硬纪律。

### 1.9 禁止项（打回线）
- 网红脸 / 锥子脸 / 欧美立体骨相 / 韩系花美男。
- 华服金冠、满身金玉（他是清贫守塔卒，不是仙尊）。
- 塑料感高光、3D 默认渲染、卡通粗描边、重度磨皮。
- 血腥、恐怖（妖兽可虚化暗示，不可直绘狰狞）。
- 背景塞满、无留白、光污染；**暖色泛滥成俗艳**（必须玄青收口）。
- 与沈碑撞脸：同一张脸换袍色——两者须可一眼区分（冷/暖 + 道具 + 气质）。
