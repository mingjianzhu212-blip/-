> 版本：**1.0** ｜ 编制：2026-11-03（第 121 轮）｜ 状态：**待启动（会员未开通）**
> 前提：**现在不开会员、不生图**。等游戏主要页面/交互稳定后，集中开通**一个月**会员，按本计划一次做完。
> 需求来源：`ART_ASSET_MASTER_LIST.md`（唯一口径）。本计划**不新增任何清单外的图**。

## 0. 为什么要这样调整（一句话）

生图最贵的不是次数，是**"边开发边临时想画什么"**。把需求、尺寸、路径、验收全部前置，会员期内只做三件事：**出图 → 筛图 → 归档**。

**本计划解决的三个浪费：**
1. 页面还在改就生图 → 图跟着返工（例：P1-A 道途是新功能，早生图就白做）。
2. 没有清单就生图 → 生成一堆"看着好看但用不上"的图（C 级 10 张已明确不做）。
3. 没有尺寸/透明规范 → 出图后发现不能直接用（例：`hero_male.png` 带底，进战斗台就是白方块）。

### 2.3 开通当天必须实测的三件事（不实测不开工）

1. **每日/每月生成额度**：会员页写的额度 vs 实际可用次数（部分档位有"快速生成"与"慢速不限"之分）。

> 这三项的结论若与预期不符（如会员仍带水印、或商用需额外授权），**暂停生产**，先回报，不硬着头皮生。

## 4. 每批的固定动作（出图当天就做完，不攒）

### 4.1 出图 → 筛图（当天筛，不隔夜）

| 步骤 | 动作 | 淘汰标准（任一命中即废） |
|---|---|---|
| 1 | 一次出 3 张候选 | — |
| 2 | 缩到 **64px** 看还认不认得出 | 认不出 → 废（清单 QA-A2 硬指标） |
| 3 | 查锚点 | 沈碑少扫帚/多金饰 → 废；崔九像沈碑 → 废 |
| 4 | 查规格 | 非透明/带水印/带文字 → 废 |
| 5 | 查手/脸 | 手部畸形、脸崩、多指 → 废 |
| 6 | 通过者标 `_candidate` | — |

> **宁可少，不凑数**。36 张里若有 5 张是"凑合能用"，等于整批质感被拉低。

### 4.2 归档 → 备份（当天做）

```
art-pipeline/
├─ production/
│  ├─ 2026-MM-DD_batch1_shenbei/
│  │  ├─ raw/          原始出图（含被淘汰的，留证）
│  │  ├─ candidate/    候选（命名带 _candidate）
│  │  ├─ final/        定稿（命名带 _final）
│  │  └─ batch.md      本批记录：提示词版本 / seed / 淘汰原因
```

- 定稿当天复制进 `ui/` 对应目录，**并按 `MASTER_LIST §5.2` 命名**。
- **旧文件先存 `_v0` 再替换**（`hero_male/female.png`、`npc_stele_full.jpg` 永不覆盖）。
- 每批结束追加 `CREDITS_LEDGER.md`：生成平台/档位/张数/是否带水印。

### 4.3 什么情况下停下来回报（不硬推）

1. 连续 **8 张候选全废** → 说明提示词或参考图策略错了，停下改提示词，不要靠次数硬刷。
2. 出现**商用授权不明**（会员档位与授权不符）→ 停工，等核实。
3. 会员额度**用掉 70% 但定稿不足 50%** → 收缩到只做 A 级 21 张，放弃 B 级。
4. 主线 A 临时改了页面结构（如 P2 镇妖塔重做）→ 受影响批次暂停。

## 6. 风险与预案

| 风险 | 概率 | 预案 |
|---|---|---|
| **扫帚画成杖/棍** | 高 | 负面词加 `长杖, 手杖`；正向写"竹柄磨亮、帚毛散开沾灰"；仍不行则改用"斜倚在碑上的扫帚"（避开手持姿势） |
| **参考图带偏画风**（越生成越糊/越像二次元） | 中 | 每次只用 1 张参考图，不叠图；每批首张必对照 P1 原图 |
| **透明边缘白边/毛边** | 高 | 出图后统一走抠图；边缘发灰的用"深色背景版"重出，不在白底上抠 |
| **两位老 NPC 撞脸** | 中 | 冷暖分野 + 道具分野；并列比对通过才进第 2 批 |
| **Boss 立绘没有压迫感** | 中 | 先定剪影（黑稿），剪影过了再细化 |
| **额度不够** | 中 | 已在 §2.1 只排 36 张；不足时优先保 A 级 21 张 |
| **会员临期未返工完** | 中 | D29–D30 为缓冲；仍不够则接受"部分定稿标 candidate"，上线只用 final |

## 7. 本计划的诚实边界

1. **没有实测过即梦的额度/水印/商用条款**——§2.3 写明开通当天必须实测，且 `LICENSE_CHECKLIST.md` 里全部标"待核实"。
